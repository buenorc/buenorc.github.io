General Lake Model (1-D)

Vertically-resolved, computationally cheap — ideal for continuous high-frequency operation. Runs in operational mode with sequential state updates, so each forecast starts from the previous reservoir state plus new meteorological forcing (as done for Lake Erie).

Delft3D-FLOW (3-D)

Resolves horizontal circulation, upwelling and spatial temperature that a 1-D model cannot. Calibrated on historical Passaúna campaigns and validated against the continuous monitoring network; supports data assimilation (EnKF) for near-real-time correction.
